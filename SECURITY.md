# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `redberry/laravel-cloud-sdk`, please email **hello@redberry.ge** with the details. Do not open a public issue, pull request, or discussion — security reports must be handled privately until a fix is available.

You can expect an acknowledgement within three business days and a coordinated disclosure timeline once the report is validated.

## Supported Versions

Security fixes are provided for the latest minor release of the current major version. Older majors receive fixes only for critical issues on a best-effort basis.
